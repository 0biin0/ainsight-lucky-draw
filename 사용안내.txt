AInsight 럭키드로우 — 저장·터치 관리자

실행: 폴더 전체를 압축 해제하고 index.html을 여세요.
GitHub Pages: 이 폴더 안 내용물을 저장소 루트에 올리세요. index.html, audio.js, MP3 4개, images, fonts를 함께 유지합니다.

1. 다음 날 이어서 진행
- 추첨 즉시 번호별 경품 배정, 당첨 번호/등수/시간, 확인 전 당첨 화면을 자동 저장합니다.
- 같은 기기·같은 브라우저·같은 웹 주소로 다시 열면 마지막 상태를 복원합니다.
- 날짜가 바뀌거나 브라우저를 닫아도 자동 초기화하지 않습니다.
- 하단 저장 완료 메시지를 확인하세요. 오류가 표시되면 관리자에서 진행 상태 백업을 저장하세요.
- 관리자 '지금 저장'으로 수동 저장도 가능합니다.
- 시크릿 모드, 사이트 데이터 삭제, 다른 브라우저 사용은 피하세요.
- 브라우저가 데이터를 지우거나 기기가 고장 나는 경우까지 자동 저장이 보장되지는 않습니다. 행사 종료 후 JSON 백업을 별도로 보관하세요.

2. 터치 관리자
- 관리자 메뉴 → 숫자판에 2468 입력 → 확인.
- 관리자 안의 비밀번호 변경에서 새 숫자 4자리를 두 번 입력합니다.
- 비밀번호는 해당 브라우저에 저장됩니다. 다른 기기에서는 기본값 2468로 시작합니다.
- 초기화도 숫자판으로 비밀번호 확인 후 실행/취소 버튼을 누릅니다. 키보드가 필요하지 않습니다.
- 전체 초기화는 새 행사를 시작할 때만 사용하세요. 다음 날 이어서 할 때는 누르지 마세요.
- 실수로 초기화했다면 '초기화 전 상태 복구'로 가장 최근 초기화 직전 기록을 복구할 수 있습니다.
- 이 PIN은 현장 오조작 방지용이며 서버 인증 기능은 아닙니다.

3. 별도 백업과 복원
- 진행 상태 백업: 다시 복원할 수 있는 JSON 파일을 다운로드합니다. 실제 다운로드 완료 여부를 기기에서 확인하세요.
- 백업 불러오기: 저장한 JSON 선택 → 당첨 건수 확인 → 실행.
- 잘못된 파일은 거부합니다. 복원 전에 현재 상태의 별도 사본도 브라우저에 보관합니다.
- CSV 내보내기는 목록 확인용이며 복원용이 아닙니다.
- JSON 백업에는 아직 열지 않은 번호의 경품 배정도 포함되므로 관리자만 보관하세요.
- 파일 위치 또는 로컬 파일에서 GitHub Pages로 실행 주소가 바뀌면 기존 저장 기록이 자동 이동하지 않을 수 있습니다. 실제 행사 전에 최종 주소에서 추첨 1회 → 닫기 → 재접속하여 복원 확인 후 관리자에서 테스트 기록을 초기화하세요.
- 기존 버전과 같은 웹 저장소에서 실행하면 기존 저장 키를 그대로 읽습니다. 이번에 제공한 폴더에는 실제 사용자의 브라우저 기록이 포함되어 있지 않습니다.

4. 음원과 화면
- 첫 버튼 터치 또는 BGM 시작으로 반복 배경음악을 시작합니다.
- BGM 음량 및 ON/OFF, 1등 전용 당첨음, 2~8등 당첨음, 버튼 클릭음을 유지했습니다.
- 기존 PAPERLOGY와 전체화면 수정 스타일을 유지했습니다.
- 스탠바이미 실제 기기의 터치·저장·파일 선택/다운로드·음원 재생은 행사 전 확인하세요.
